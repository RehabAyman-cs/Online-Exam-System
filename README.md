Online Exam System

Description

A console-based math exam application developed using C++. Users can choose the number of questions, difficulty level, and question type. The system checks answers and displays the final results.

Features

- Choose question count and difficulty level.
- Select arithmetic operations.
- Check answers and count correct and incorrect responses.
- Display the final result (Pass or Fail).
- Play again.

Technologies

- C++
- Enums
- Functions
- Loops and Conditional Statements
